*Respuestas Reflexión Final*

*1.¿Qué diferencia observó entre un archivo modificado, preparado y confirmado?*

**R//** Un archivo modificado es cuando hacemos un cambio en el proyecto, pero Git aún no lo considera parte del próximo registro.
        Un archivo preparado es donde se arma lo que exactamente va a llevar el siguiente commit.
        Un archivo confirmado es cuando el cambio ya forma parte del historial y es recuperable.

*2.¿Por qué tres commits pequeños son más útiles que uno solo?*

**R//** Porque al ser commits pequeños se hace más fácil revisar cambios, avanzar en el historial viendo como
        evoluciona el proyecto de manera ordenada. En caso de que haya algún fallo fácilmente se puede encontrar
        el commit que causó el problema y solucionarlo.

*3. ¿Qué mensaje de commit considera más claro y por qué?*

**R//** De los que hice creo que el commit más claro es el de "Feat: cambio de mensaje en CampusStatus.java", porque
        se entiende claramente que hice y dónde lo hice.
